# Mind Poker

## 📖 About This Project
This project was originally my Diploma Final Year Project (FYP) — an online two-player poker game. Unfortunately, the original project files were lost due to severe server crashes and critical bugs. 

Instead of giving up, I am now **rebuilding the entire game from scratch** as a single-player experience using the **Godot Engine**.

## 🛠️ Original Project Features (Version 1.0)
Before the server wipe, the original multiplayer version featured:
* Engineered online matchmaking and synchronized gameplay for seamless two-player interaction.
* Integrated secure login system within the game to protect user accounts and data.
* Integrated cloud-based database for efficient storage, retrieval, and management of player data and game records.

## 🚀 Current Development (Godot Remake)
I am currently transforming the game to focus on offline, single-player mechanics.
* **Game Engine:** Godot
* **Game Mode:** Single-Player 
* **Status:** Work in Progress
